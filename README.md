# cs120LabGuessingGame
BSU CS 121 course: lab 1

## Algorithm

Ask the user for an input and store that as a main
 
Greet the user by name 

create a random variable between 1 and 100 and store that as the target guess 

create a counter variable that counts the amount of turns it is taking 

ask the user to guess the number 

give appropriate feed back, Too high, Too low

repeat until input is equal to the target 

take note of the amount of and tell the user how they did, below 7 is good, 7 is average, above 7 is bad

thank them for playing
